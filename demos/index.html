🎨 Matplotlib FastAPI Demo

Welcome to the matplotlib-fastapi demo! This application demonstrates how to serve interactive matplotlib plots via FastAPI and WebSockets.

📊 Full-Page Interactive Plots

View all available plots with their full interactive interface:

  • Browse All Plots
    View the complete list of available plots with descriptions and parameter schemas. Each plot includes matplotlib's standard toolbar with pan, zoom, and home buttons.

🧩 Embeddable Component

New! Framework-agnostic embeddable component for integrating matplotlib plots into your own web applications:

  • Embeddable Component Demo
    See how to embed matplotlib plots in your own HTML pages using the MatplotlibEmbeddable JavaScript class

🔌 API Endpoints

  • GET /plots
    List all available plots with their schemas (JSON)
  • GET /plots/component.js
    JavaScript bundle for embeddable component
  • GET /plots/api/plots/{name}/schema
    Get initialization and update schemas for a specific plot (JSON)
  • GET /docs
    Interactive API documentation (Swagger UI)
💡 Tip: All plots support matplotlib's standard toolbar with pan, zoom, and home buttons. Plots marked with "live updates" also have parameter adjustment forms for real-time interaction.
