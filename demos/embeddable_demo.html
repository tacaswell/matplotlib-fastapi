🎨 Matplotlib FastAPI - Embeddable Component Demo

Overview

This demo showcases the MatplotlibEmbeddable component - a framework-agnostic, composable JavaScript API for embedding interactive matplotlib figures into any web application.

Key Features:

  • Programmatic instantiation - no server-rendered HTML required
  • Full WebSocket lifecycle management
  • Dynamic parameter updates without reconnection
  • Event callbacks for connect, error, update, and disconnect
  • Auto-generated update forms from JSON schema
  • Clean JavaScript API - can be wrapped in React, Vue, Angular, etc.
  • Multiple plots on the same page

Demo 1: Basic Usage

Single plot with automatic connection and update form:

const plot = new MatplotlibEmbeddable({
    container: document.getElementById('plot1'),
    plotName: 'sine',
    baseUrl: '/plots',
    initParams: { frequency: 1.0, amplitude: 1.0 },
    onConnect: () => console.log('Connected!'),
    onUpdate: (params) => console.log('Updated:', params)
});

API Reference

Constructor Options

new MatplotlibEmbeddable({
    container: HTMLElement,       // Required: DOM element to render into
    plotName: string,              // Required: Name of the plot
    baseUrl: string,               // Base URL (default: '')
    initParams: object,            // Initial parameters (default: {})
    updateParams: object,          // Update parameters (default: {})
    onConnect: function,           // Called when connected
    onError: function(error),      // Called on error
    onUpdate: function(params),    // Called after update
    onDisconnect: function,        // Called on disconnect
    showToolbar: boolean,          // Show matplotlib toolbar (default: true)
    showUpdateForm: boolean,       // Show update form (default: true)
    staticPath: string,            // Static files path (default: '/mpl-static')
    autoConnect: boolean           // Auto-connect on create (default: true)
})

Methods

plot.connect()                  // Connect to WebSocket
plot.disconnect()               // Disconnect and cleanup
plot.update(params)             // Update plot parameters
plot.isConnected()              // Check connection status
plot.getUpdateParams()          // Get current update parameters
plot.getInitParams()            // Get initial parameters

Installation & Import Options

Option 1: npm package (for bundlers like Vite, webpack, etc.)

npm install mpl-fastapi

// In your JavaScript/TypeScript:
import { MatplotlibEmbeddable } from 'mpl-fastapi';

Option 2: Script tag (served by FastAPI)

<script src="/plots/component.js"></script>
<script>
  const plot = new MatplotlibEmbeddable({ ... });
</script>

Option 3: ES Module import (modern browsers)

<script type="module">
  import { MatplotlibEmbeddable } from '/plots/component.esm.js';
  const plot = new MatplotlibEmbeddable({ ... });
</script>
